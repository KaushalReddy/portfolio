# Kaushal Reddy Parvatala — portfolio

Next.js 14, TypeScript, Tailwind, GSAP ScrollTrigger, Lenis, React Three Fiber.

    npm install
    npm run dev      # http://localhost:3000
    npm run build

Content lives in `data/` (projects, stack, journey). Presentation lives in `components/`.
The 3D core is in `components/3d/CoreScene.tsx` and loads client-side only.
Deploy on Vercel by importing the repository; no environment variables are needed.
